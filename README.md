## e-plantShopping

Project Overview

e-plantShopping is a React-based online plant shopping application. The application allows users to browse different plants, view product information, add plants to their shopping cart, and manage their selected items.

Features
Browse a variety of plants
View plant details and prices
Add plants to the shopping cart
Increase or decrease item quantities
Remove items from the cart
View the total price of selected products
Responsive and user-friendly interface
Technologies Used
React.js
JavaScript
HTML5
CSS3
React Hooks
Project

This project was developed as part of a hands-on React application exercise to demonstrate component-based development, state management, event handling, and building an interactive shopping experience.
